## Selected Work

| Project | What it demonstrates |
| --- | --- |
| **[UCSD Prerequisite Dependency Graph](https://github.com/CuteSurtr/prereq-dependency)** | Graph modeling over a real course catalog: OR-alternative prerequisite slots, class-standing and major-code gating, and transitive-redundancy pruning, rendered as a layered DAG in a static React front end. |
| **[NurseLaunch](https://github.com/CuteSurtr/nurselaunch)** | Adapter-based integration across two applicant tracking systems, Workday and Oracle Cloud Recruiting, normalized into a single job shape with optional Redis caching, Postgres posting history, and scheduled email digests. |
| **[Cox Survival Analysis on TCGA](https://github.com/CuteSurtr/cox-survival-tcga)** | Statistical methods written from scratch — Cox partial likelihood by Newton-Raphson, Kaplan-Meier, the log-rank test, and Harrell's concordance index — run end to end against TCGA clinical data pulled live from the GDC API. |
| **[Iwasawa Decomposition in Lean 4](https://github.com/CuteSurtr/Iwasawa_Decomposition)** | Machine-checked mathematics: a complete formalization of the Iwasawa decomposition for GL_n(R), covering both existence and uniqueness, built on Mathlib's Gram-Schmidt API. |
| **[Anatomy & Physiology Study Tool](https://github.com/CuteSurtr/anatomy_physiology_study_tool)** | Content-heavy full-stack delivery: 93 MDX content pages with interactive fill-in-the-blank diagram quizzes, spaced repetition, and anonymous per-device progress tracking. |
